# Excel Sales Data Cleaning and Analysis

## Project Overview
This project demonstrates an end-to-end sales data analysis workflow using Microsoft Excel. The objective was to transform an unclean sales dataset into reliable business insights through data cleaning, analysis, and dashboard visualization.

**Note:** This is a simulated client project using a practice dataset.

## Business Objectives
- Evaluate overall sales revenue and profitability.
- Identify the best-performing products.
- Compare sales performance across cities and regions.
- Analyze monthly sales trends.
- Evaluate sales representative performance.
- Understand payment methods and order statuses.
- Identify data quality issues and document corrections.

## Tools Used
- Microsoft Excel
- Excel formulas
- PivotTables
- PivotCharts
- Data cleaning and validation
- Dashboard visualization

## Project Workflow

### 1. Data Cleaning
- Identified and removed duplicate records.
- Standardized product names, city names, and categories.
- Corrected inconsistent formatting.
- Investigated missing and invalid values.
- Documented data quality issues.
- Applied client-approved corrections.

### 2. Data Analysis
Calculated:
- Revenue after discounts
- Total product costs
- Profit
- Profit margin
- Monthly performance

Analyzed performance by product, city, region, customer, sales representative, payment method, and order status.

### 3. Dashboard
Created an Excel dashboard to present key performance indicators and business trends through charts and summary metrics.
